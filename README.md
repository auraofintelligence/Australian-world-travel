A browser-based planning guide for an Australian aiming to visit every country. It brings travel routes, diplomatic contacts, document preparation and a long-range itinerary into one static, multi-page site.

**Public site:** <https://auraofintelligence.github.io/Australian-world-travel/>

## What is included

- `index.html` - searchable country and business-visa planning cards plus a trip shortlist.
- `missions.html` - foreign diplomatic missions in Australia.
- `abroad.html` - Australian diplomatic missions overseas, including a map.
- `strategy.html` - the 11-year route blueprint, itinerary tools and an agent update log.
- `documents.html` - document, translation, notarisation and apostille planning prompts.
- `logistics.html` - a browser-local visa and logistics tracker.

## Use it locally

Open `index.html` in a browser. There is no build step. Some maps, fonts and interface libraries are loaded from public services, so those parts need an internet connection.

The logistics tracker stores entries in the current browser's `localStorage`. It is not a secure document vault: keep passport scans, identity records, financial information and other sensitive material out of the public site and repository.

## Status and source boundary

This is a planning prototype, not an official visa, legal or travel-advice service. Its embedded country, mission and document information is a snapshot and can become outdated. Confirm entry rules, permitted activities, dates, fees and contacts with the relevant government, embassy, consulate or other primary source before acting.
